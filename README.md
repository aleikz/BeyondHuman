Beyond Human is a multiplayer platform-fighting game centered around supernatural abilities. Players choose an ability class and use unique powers to fight against their opponents in an arena.

The project was developed as a game development project and focused on creating a playable combat prototype within a limited development timeframe.

**Features**
- platform-fighting gameplay
- supernatural ability classes
    - Fire-based abilities
    - Psychic abilities
- Player movement and combat
- Arena-based gameplay

**Abilities**
Fire
* Fireball
* Fire Pillar
* Flame Dash

Psychic
* Push
* Pull
* Stun

Technologies
- Unity
- C#
